# 🖥️ Process Scheduling Simulator with Shell Interface

A **C-based Operating System project** that simulates CPU process scheduling algorithms through a custom **shell interface**.

## 🚀 Features

* Custom shell interface
* FCFS Scheduling
* SJF Scheduling
* Round Robin Scheduling
* Priority Scheduling
* Process management
* Waiting Time calculation
* Turnaround Time calculation
* Response Time calculation
* Average performance analysis

## 🧠 Scheduling Algorithms

| Algorithm   | Description                   |
| ----------- | ----------------------------- |
| FCFS        | First Come First Serve        |
| SJF         | Shortest Job First            |
| Round Robin | Time Quantum based scheduling |
| Priority    | Priority based scheduling     |
